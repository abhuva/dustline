FIELD NOTES

A recipe, not a painted map.

Add operations from the left and connect compatible ports. Drag nodes to organize the recipe; pan empty space and use the wheel to zoom. Undo and redo include graph edits.

Playable world keeps the largest connected floor area and places the initial spawn and six outposts. Ground materials, Enemy spawns, Decoration, art banks, and shop profiles remain independent outputs and profiles.

Placements shows the real playable result. Saved World Map connections add gold reserved corridors, exact edge roads, cyan triggers, and pale arrival points after base generation. Manual Player Spawns remain available for New Game and testing; ordinary region travel does not use them.

In World map, every enabled region has fixed north, east, south, and west ports. Connect complementary sides to create one reciprocal link. Node positions are presentation only; bracketed coordinates are derived from topology. Disconnected drafts can be saved, while release builds require one connected component. Atlas generates clean 128×128 schematics at those derived coordinates.

Save map or world changes, run ./build.ps1, and rebuild the editor engine with ./map-editor.ps1 -BuildOnly after native preview-kernel changes.

 PER-MAP ENCOUNTERS

Population profiles

Input B of Enemy spawns chooses these profiles by byte ID. Input A independently controls placement density. Each profile owns its vehicle, respawn time, and loot table.

Use Constant field, Stepped LUT, or Paint field value to author the profile-ID regions connected to input B.

 REGIONAL PROGRESSION

Shop profile

Stock is compiled from this profile, the stable region ID, seed, town index, and global item catalog. Tier chooses placement only; it never gates a purchase at runtime.
